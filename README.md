# E-commerce ETL Pipeline

## 1. Project Introduction

This is my first Data Engineering project.

The main objective of this project is to extract data from CSV files, clean the data using Python, and load the processed data into a PostgreSQL database.

## 2. Technologies Used

- Python
- PostgreSQL
- Git
- GitHub
- Pandas
- SQL

## 3. Project Workflow

1. Extract data from CSV files.
2. Read data using Python.
3. Remove duplicate records.
4. Validate data.
5. Load clean data into PostgreSQL.
6. Generate reports using SQL.

## 4. Project Structure

```text
project1/
│
├── data/
│   └── orders.csv
│
├── main.py
├── .gitignore
└── README.md
```

## 5. Installation

Install the required Python packages:

```bash
pip install pandas psycopg2-binary
```

## 6. How to Run

1. Clone the repository.
2. Install the required packages.
3. Create a PostgreSQL database named `ecommerce_db`.
4. Configure the database connection.
5. Run the Python script:

```bash
python main.py
```
